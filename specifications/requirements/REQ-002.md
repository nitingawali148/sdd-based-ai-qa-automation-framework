# REQ-002: User Management API

## User Story
As an administrator, I want to create, view, update and delete users through the API so that I can manage access to the application.

## Objective
Provide a secure REST API for managing application users.

## Business Rules
- Only authenticated clients can use the user management API.
- A user email must be unique.
- A user name is required and must be at most 100 characters.
- A user role must be one of: admin, viewer.

## Input Fields
| Field | Type | Required | Rules |
|---|---|---|---|
| name | string | yes | 1-100 characters |
| email | email | yes | unique |
| role | enum | yes | admin, viewer |

## Acceptance Criteria
- AC-001 [API]: Given an authenticated admin, when they create a user with a valid name, email and role, then the API returns 201 and the created user.
- AC-002 [API]: Given an authenticated admin and an existing user, when they create a user with the same email, then the API returns 409 with "Email already exists".
- AC-003 [API]: Given an authenticated admin, when they create a user with an empty email, then the API returns 422.
- AC-004 [API]: Given an authenticated admin and an existing user, when they retrieve the user by id, then the API returns 200 and the user.
- AC-005 [API]: Given an authenticated admin, when they list users, then the API returns 200 and the list of users.
- AC-006 [API]: Given an authenticated admin and an existing user, when they update the user with a valid name, email and role, then the API returns 200 and the updated user.
- AC-007 [API]: Given an authenticated admin and an existing user, when they partially update the user role, then the API returns 200 and the updated user.
- AC-008 [API]: Given an authenticated admin and an existing user, when they delete the user, then the API returns 204.
- AC-009 [API]: Given an unauthenticated client, when they list users, then the API returns 401.

## API
- POST /api/users - Create a user
- GET /api/users - List users
- GET /api/users/{user_id} - Get a user
- PUT /api/users/{user_id} - Replace a user
- PATCH /api/users/{user_id} - Partially update a user
- DELETE /api/users/{user_id} - Delete a user

## Non-Functional Requirements
- User management API responses must complete within 1 second at the 95th percentile.

## Dependencies
- REQ-001: an access token is obtained through the login API.
