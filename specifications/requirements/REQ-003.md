# REQ-003: Password Reset

> Deliberately incomplete sample: it shows the Specification Validation gate stopping an ambiguous
> requirement and asking for clarification instead of inventing behaviour.

## User Story
As a user who forgot my password, I want to reset it so that I can log in again.

## Business Rules
- The reset link should expire after an appropriate time.
- The new password must be secure.

## Input Fields
| Field | Type | Required | Rules | UI Label |
|---|---|---|---|---|
| email | email | yes | | Email |

## Acceptance Criteria
- AC-001 [UI]: Given a registered user, when they request a password reset, then they receive an email quickly.
- AC-002 [UI]: Given an unregistered email, when the user requests a reset, then an appropriate message is shown.

## UI
| Page | Path | Elements |
|---|---|---|
| Forgot Password | /forgot-password | Email (textbox), Send reset link (button) |
