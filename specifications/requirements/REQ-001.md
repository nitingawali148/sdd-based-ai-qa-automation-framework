# REQ-001: User Login

## User Story
As a registered user, I want to log in with my email and password so that I can access my dashboard.

## Objective
Allow registered users to log in securely.

## Business Rules
- Only registered users can log in.
- The email must be a valid email address.
- The password must be between 8 and 64 characters.
- Invalid credentials must not reveal whether the email or the password was wrong.

## Input Fields
| Field | Type | Required | Rules | UI Label |
|---|---|---|---|---|
| email | email | yes | max 254 characters | Email |
| password | password | yes | 8-64 characters | Password |

## Acceptance Criteria
- AC-001 [UI, API]: Given a registered user, when they submit a valid email and password, then they are navigated to the Dashboard page.
  - API: returns 200 with "access_token"
- AC-002 [UI, API]: Given a registered user, when they submit an invalid password, then the error message "Invalid email or password" is displayed.
  - API: returns 401 with "Invalid email or password"
- AC-003 [UI]: Given the Login page, when the user submits an empty email, then the validation message "Email is required" is displayed.
- AC-004 [UI]: Given the Login page, when the user submits an empty password, then the validation message "Password is required" is displayed.
- AC-005 [UI, API]: Given an unregistered email, when the user submits it with a password, then the error message "Invalid email or password" is displayed.
  - API: returns 401 with "Invalid email or password"
- AC-006 [UI]: Given the Login page, when the user submits a password shorter than 8 characters, then the validation message "Password must be at least 8 characters" is displayed.

## UI
| Page | Path | Elements |
|---|---|---|
| Login | /login | Email (textbox), Password (textbox), Sign in (button) |
| Dashboard | /dashboard | Dashboard (heading), Sign out (button) |

## API
- POST /api/auth/login - Authenticate a user and issue an access token

## Non-Functional Requirements
- Login API response time must be under 2 seconds at the 95th percentile.
- Passwords must never be written to logs.
- Authentication must follow the approved security requirements (OWASP ASVS L1).

## Dependencies
- A registered test user is available in the target environment.
