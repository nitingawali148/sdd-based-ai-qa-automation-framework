## Objective
Provide a secure REST API for managing application users.

## User Story
As an administrator, I want to create, view, update and delete users through the API so that I can manage access to the application.

## Functional Requirements
- **FR-001**: The user must provide name (string, required, 1-100 characters).
- **FR-002**: The user must provide email (email, required, unique).
- **FR-003**: The user must provide role (enum, required, admin, viewer).
- **FR-004**: The system must provide POST /api/users: Create a user.
- **FR-005**: The system must provide GET /api/users: List users.
- **FR-006**: The system must provide GET /api/users/{user_id}: Get a user.
- **FR-007**: The system must provide PUT /api/users/{user_id}: Replace a user.
- **FR-008**: The system must provide PATCH /api/users/{user_id}: Partially update a user.
- **FR-009**: The system must provide DELETE /api/users/{user_id}: Delete a user.

## Business Rules
- **BR-001**: Only authenticated clients can use the user management API.
- **BR-002**: A user email must be unique.
- **BR-003**: A user name is required and must be at most 100 characters.
- **BR-004**: A user role must be one of: admin, viewer.
