## Objective
Allow registered users to log in securely.

## User Story
As a registered user, I want to log in with my email and password so that I can access my dashboard.

## Functional Requirements
- **FR-001**: The user must provide Email (email, required, max 254 characters).
- **FR-002**: The user must provide Password (password, required, 8-64 characters).
- **FR-003**: The system must provide POST /api/auth/login: Authenticate a user and issue an access token.
- **FR-004**: The system must provide the Login page at /login.
- **FR-005**: The system must provide the Dashboard page at /dashboard.

## Business Rules
- **BR-001**: Only registered users can log in.
- **BR-002**: The email must be a valid email address.
- **BR-003**: The password must be between 8 and 64 characters.
- **BR-004**: Invalid credentials must not reveal whether the email or the password was wrong.
